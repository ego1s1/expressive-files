Expressive Files is an open source file manager built with Material 3 Expressive.

Features:
- Open source: Lightweight, clean and secure.
- Material 3 Expressive: Dynamic color, expressive motion and accessible components.
- Breadcrumbs: Navigate the filesystem with ease.
- Root support: View and manage files with root access.
- Archive support: View, extract and create common compressed files.
- NAS support: View and manage files on FTP, SFTP, SMB and WebDAV servers.
- Themes: Dynamic color, true black and custom accent colors.
- Linux-aware: Knows symbolic links, file permissions and SELinux context.
- Robust: Uses Linux system calls under the hood, not yet another ls parser.
- Well-implemented: Built on Java NIO2 File API and modern Android architecture.

Based on Material Files by Hai Zhang (GPLv3).

https://github.com/ego1s1/expressive-files
