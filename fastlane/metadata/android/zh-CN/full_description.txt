Expressive Files 是一个使用 Material 3 Expressive 构建的开源文件管理器。

功能：
- 开源、轻量且安全。
- Material 3 Expressive：动态取色、表现力动效和无障碍组件。
- 面包屑、列表/网格、搜索、排序和选择。
- Root、压缩包以及 FTP/SFTP/SMB/WebDAV 服务器。
- 纯黑主题、动态取色和动画设置。
- 支持符号链接、权限和 SELinux 上下文。
- 基于 Java NIO2 File API 和现代 Android 架构。

基于 Hai Zhang 的 Material Files（GPLv3）。

https://github.com/ego1s1/expressive-files
