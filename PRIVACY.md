# Privacy Policy

Expressive Files is an open source, local-first file manager. It does not collect,
upload or sell personal data.

## Data handling

- Files, folder names, thumbnails and search results are processed on the device.
- App preferences and credentials for user-configured servers are stored locally on the
  device.
- Network access is used only when the user opens a remote server (FTP, SFTP, SMB,
  WebDAV) or follows a link. The app does not operate an analytics or advertising
  backend.
- The app does not request an account and does not include Firebase Analytics or an
  advertising SDK.

## Permissions

Storage, network and notification permissions are used only for file browsing, remote
servers, and the optional FTP server foreground service. Android controls these
permissions and the user can revoke them at any time.

## Third-party components

The app includes open source libraries listed in the in-app licenses screen. Server
connections go directly to the server the user configures; those servers have their own
privacy practices.

## Contact
