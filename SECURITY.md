# Security Policy

## Supported Versions

Only the latest release of Expressive Files receives security updates.

## Reporting a Vulnerability

Do not open a public issue for a security problem. Use GitHub's private vulnerability
reporting:

<https://github.com/ego1s1/expressive-files/security/advisories/new>

Include the affected version, Android API level, reproduction steps and impact. You
will receive an acknowledgement before any public disclosure.
